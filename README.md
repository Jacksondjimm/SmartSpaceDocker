# SmartSpaceDocker
Программное обеспечение для сервера домашнего климат контроля (на базе Raspberry Pi).

Папка bme280 содержит программный код среды Arduino IDE для платы на базе ESP-01 и датчика температуры и влажности bme280 (далее Wi-fi датчик температуры).
Wi-fi датчики температуры размещены в разных комнатах квартиры.

Папка WebApplication содержит Backend API проект на базе C# Razor Pages, Postgre SQL server и API для передачи данных для Frontend проекта.
Razor Pages сохранены для отображения данных для проверки работы Backend проект и отладки дальнейших изменений.

Папка RazorPagesApp содержит Frontend UI проект на базе C# Razor Pages для получения и отображения данных от Backend API проекта.

Всего установлено 3 Wi-fi датчика температуры из 5. Каждый Wi-fi датчик температуры транслирует данные на сервер по Wi-fi.

На сервере работают контейнеры docker c проектами Frontend UI и Backend API на базе ASP.NET и контейнер docker с Postgre SQL 
(развёрнуто на Raspberry Pi). По каждому датчику глубина архива составляет 1000 показаний в данной версии программы. Архив пишется "по-кругу".
Данные от датчиков передаются 1 раз в 5 минут.
Позже добавлю ссылку на схему платы датчика на на моей страничке в https://easyeda.com/. По корпусу датчика инфа будет позже.

При запуске Backend API или Frontend UI проека в Visual Studio, выводится ошибка "docker-compose.dcproj : error  : Невозможно найти файл проекта.".
Ошибка связана с тем, что "docker-compose.yml" перемещён на уровень выше в общий каталог для запуска всего проекта (Backend API, Frontend UI и Postgre) и в связи с чем "docker-compose.dcproj" удалён. В такой ситуации проект целиком можно запустить из терминала. 
Альтернативный вариант запуска для отладки в Visual Studio: необходимо запустить RazorPagesApp.sln в проектах Backend API (запускать первым) и Frontend UI и тем самым убедиться в работе проекта (во время запуска необходмо выбрать http, а не Container (Dockerfile)).
